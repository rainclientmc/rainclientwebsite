Setup

Three steps. Then play.

01

Install Fabric

Run the Fabric installer for Minecraft 1.21.11 and grab Fabric API from Modrinth.

Fabric API →
02

Drop in Rain

Press Win + R, open %appdata%\.minecraft\mods and put both .jar files inside.

Download Rain →
03

Launch & tune

Start the Fabric profile, press Right Shift, and pick a profile or build your own.
