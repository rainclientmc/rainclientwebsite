RUNNING.

Everything you need to install Rain Client and start dominating.

Fabric API

The essential lightweight modding API for Minecraft. Required for Rain Client to function properly.

Download on Modrinth →

Rain Client

The ultimate utility client for Minecraft 1.21.11. Download the latest .jar file and drop it into your mods folder.

Download Client →
1

Install Fabric Loader

Download and run the Fabric Installer for Minecraft 1.21.11. Select "Install" to create a new Fabric profile in your Minecraft launcher.

2

Download Fabric API

Download the Fabric API from Modrinth using the button above. Make sure to select the 1.21.11 version.

3

Place in Mods Folder

Press Win + R, type %appdata%\.minecraft, and hit Enter. Open the mods folder (create it if it doesn't exist) and drop both the Fabric API and Rain Client `.jar` files inside.

4

Launch and Configure

Open your Minecraft Launcher, select the Fabric profile, and launch the game. Once in-game, press Right Shift to open the Rain Client ClickGUI.

How do I install the client?+
